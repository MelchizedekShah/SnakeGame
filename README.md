## How to play

Clone the repository:

```sh
git clone https://github.com/MelchizedekShah/SnakeGame.git
```

Enter the project directory:

```sh
cd SnakeGame
```

Build the game:

```sh
odin build .
```

Run the executable:
```sh
./SnakeGame
```
